# PyTrivia-Winter-Project-2024

This project is a timed trivia game made using Python. Multithreading was used for printing out the timer and allowing user input simultaneously.

Rules:
-
1. Select a difficulty mode (a time control in seconds) and a category.
2. In up to three attempts per question, try to answer all 5 questions correctly in the allotted time.
3. If all the questions are answered correctly, you have a chance to boost your score!
4. Lowercase single-word answers only.
